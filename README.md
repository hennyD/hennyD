## Practice

**AI and AGI security.** Agent permissions, prompt injection, tool misuse, sensitive-data leakage, and an audit trail for every allow, block, or approval. Agents are probabilistic, so a static test is not a control. [Agent Breakout](https://github.com/hennyD/AWS-AI-Security-Hackathon-) runs the same attack against an over-permissioned agent and a guarded one. The guarded path blocks, requires a person, and records the decision. Enforcement in that demo is a local policy, and the project says so.

**SI security.** Security intelligence as an operating practice: SIEM, cyber threat intelligence, detection, and incident response. A public recommendation from the Teradata work cites vulnerability assessment, Splunk, Palo Alto, and web application security. The public detection example is [after-hours access and large-transfer review](https://github.com/hennyD/abnormal-after-normal-working-hours-login-user_and_abnormal-transfer-data-in-excess-of-50MB.), a Python pass over audit logs for repeated logons outside business hours and transfers above 50MB.

**Post-quantum.** Inventory and migration planning for RSA and elliptic-curve cryptography before the break is practical. Note: [PQC](https://www.linkedin.com/pulse/pqc-henok-teketay-obzic). This is readiness writing, not a deployed post-quantum library.

**Human-centric and global.** Least privilege and a human approval gate, plus education so institutions can actually run the control. Co-founder of [Gnzabe](https://www.linkedin.com/company/gnzabe), for cybersecurity education and awareness. InfraGard member since 2019. English and Amharic, with working Swahili.
